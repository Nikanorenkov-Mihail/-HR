# HR-ассистент в Telegram

Первый рабочий каркас relay-системы между Telegram на VPS и OpenCode на постоянно включённом ПК. Бот ограничен одним Telegram user ID, принимает текстовые запросы, показывает «Размышление» и редактирует это сообщение после ответа агента. Содержимое запросов и ответов хранится в SQLite очереди на VPS; деловые задачи и память остаются ответственностью агента на ПК.

## Состав

- `relay_bot/` — Telegram long polling, SQLite очередь, внутренний API и доставка ответов/напоминаний.
- `connector/` — фоновый процесс ПК: исходящий HTTPS polling VPS и вызов локального OpenCode API.
- `docs/` — архитектура, ограничения, инструкции агенту и настройка интеграции.
- `docker-compose.yml` — запуск relay на VPS за HTTPS reverse proxy.

## Учёт обновлений OpenCode

Connector при запуске и далее по интервалу читает версию из `/global/health`. При смене версии повторно сверяет `/doc`, нужный endpoint сессии и наличие агента `hr-assistant`. Пока контракт не подтверждён, задания не забираются. Это уменьшает риск тихого сбоя после обновления, но перед обновлением OpenCode всё равно следует сверять release notes и проверять интеграцию на тестовой сессии.

## Первый запуск

1. На VPS скопировать `.env.example` в `.env`, задать токен Telegram, свой числовой Telegram user ID и случайный `RELAY_TOKEN` не короче 32 символов.
2. Указать в `DOMAIN` домен с DNS A-записью на VPS или его публичный IPv4. Открыть входящие TCP-порты 80/443 (UDP 443 необязателен). Запустить `docker compose up -d --build`: Caddy автоматически получает HTTPS-сертификат и проксирует запросы во внутреннюю сеть Docker. Для IP используется профиль Let's Encrypt `shortlived`; сертификат действует шесть дней и обновляется Caddy автоматически. Порт relay API напрямую наружу не публикуется.
3. На ПК установить Python 3.12+, `pip install -r requirements.txt`, скопировать `connector/.env.example` в `connector/.env` и указать публичный HTTPS URL relay и тот же `RELAY_TOKEN`.
4. Запустить OpenCode `serve` на localhost с Basic Auth из корня проекта, чтобы сервер загрузил правильную конфигурацию и agent с именем `hr-assistant`. Подключить инструкции из `docs/deepseek-agent-instructions.md` и ограниченные инструменты.
5. Запустить connector из каталога проекта: `python -m connector.worker`. Connector автоматически читает `connector/.env`; supervisor может переопределить значения переменными окружения.

Не размещайте секреты в репозитории. OpenCode должен работать под Windows-пользователем, которому доступны проект, профиль провайдера и разрешённые инструменты.

## Текущие границы

Relay и connector реализуют транспортный контур. Интеграции долговременной памяти, Google Calendar и пробуждения агента по таймеру ещё не реализованы. API приёма уведомлений уже предусмотрен, но агенту пока нужен ограниченный tool/MCP wrapper, который будет его вызывать. До такой настройки бот не создаёт календарные события и не формирует напоминания самостоятельно.
